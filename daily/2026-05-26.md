## 学习笔记

### MCP vs A2A 深度对比

**核心发现**：
- **MCP**（Anthropic）= Agent ↔ Tool，纵向集成。Agent 通过 JSON-RPC 调用 MCP Server 暴露的 Tools/Resources/Prompts。
- **A2A**（Google）= Agent ↔ Agent，横向协作。Agent 通过 Agent Card 发现彼此、通过 Task 机制协作。
- **互补而非竞争**：MCP 让 Agent 有能力（工具），A2A 让 Agent 有队友（协作）。

详见 → `research/mcp-vs-a2a.md`

### Uniswap V2 Router 合约分析

**合约**: `0x7a250d5630B4cF539739dF2C5dAcb4c659F2488D` (UniswapV2Router02)

用 Hermes 分析了这个以太坊上最常被调用的合约：
- 三层架构：Router → Factory → Pair
- 6 个 swap 函数、2 个 addLiquidity、2 个 removeLiquidity
- 安全机制：amountOutMin（滑点保护）、deadline（抢跑保护）
- 这段分析正是我 Week 2 proposal 要做的产品原型

详见 → `research/uniswap-v2-router-analysis.md`
